# Pezão Imóveis

Site da Pezão Imóveis, imobiliária de Itapuranga - GO há mais de 30 anos.

- `index.html`: o site
- `dados.json`: imóveis, contatos e textos (o site lê daqui)
- `fotos/`: fotos dos imóveis
- `logo.png`: logomarca

Para mudar um imóvel, edite o `dados.json`. O painel da imobiliária só funciona na versão do site no claude.ai.
